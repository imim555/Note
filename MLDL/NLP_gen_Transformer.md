
# Transformer

트랜스포머(Transformer)는 2017년 구글이 발표한 논문인 "Attention is all you need"에서 나온 모델로 기존의 seq2seq의 구조인 인코더-디코더를 따르면서도, 논문의 이름처럼 어텐션(Attention)만으로 구현한 모델이다. 이 모델은 RNN을 사용하지 않고, 인코더-디코더 구조를 설계하였음에도 번역 성능에서도 RNN보다 우수한 성능을 보여준다


트랜스포머는 RNN을 사용하지 않지만 기존의 seq2seq처럼 인코더에서 입력 시퀀스를 입력받고, 디코더에서 출력 시퀀스를 출력하는 인코더-디코더 구조를 유지한다
이전 seq2seq 구조에서는 인코더와 디코더에서 각각 하나의 RNN이 t개의 시점(time step)을 가지는 구조였다면 이번에는 인코더와 디코더라는 단위가 N개로 구성되는 구조이다
트랜스포머를 제안한 논문에서는 인코더와 디코더의 개수를 각각 6개 사용한다

#  Positional Encoding

- 트랜스포머는 <span style="background:rgba(240, 107, 5, 0.2)">RNN 처럼 단어 입력을 순차적으로 받는 방식이 아니</span>므로 <span style="background:rgba(240, 107, 5, 0.2)">단어의 위치 정보</span>를 다른 방식으로 알려줄 필요
- 단어의 위치 정보를 얻기 위해서 각 단어의 <span style="background:rgba(240, 107, 5, 0.2)">임베딩 벡터에 위치 정보들을 더하여</span> 모델의 입력으로 사용하는데, 이때 위치정보를 포지셔널 인코딩 값이라 한다.
- 이에 따라 트랜스포머의 입력은 순서 정보가 고려된 임베딩 벡터가 된다. 같은 단어라고 하더라도 문장 내의 위치에 따라서 트랜스포머의 입력으로 들어가는 임베딩 벡터의 값이 달라지는 것이다.

![[Pasted image 20250313154927.png]]

임베딩벡터와 포지셔널 인코딩 벡터를 더하여 입력벡터를 가공한다
![[Pasted image 20250313154951.png]]


- 포지셔널 인코딩 계산
	$PE_{(pos,\ 2i)}=sin(pos/10000^{2i/d_{model}})$
	$PE_{(pos,\ 2i+1)}=cos(pos/10000^{2i/d_{model}})$
	- pos : 입력 문장에서의 임베딩 벡터의 위치
	- i : 임베딩 벡터 내의 차원의 인덱스. 임베딩 벡터 내의 각 차원의 인덱스가 짝수인 경우에는 사인 함수의 값을 사용하고 홀수인 경우에는 코사인 함수의 값을 사용
	- $d_{model}$ : 트랜스포머의 모든 층의 출력 차원을 의미하는 하이퍼파라미터

인코더의 셀프 어텐션 : Query = Key = Value => 본질적으로 Query, Key, Value가 동일한 경우

# Encoder

- 트랜스포머는 하이퍼파라미터인 num_layers 개수의 인코더 층을 쌓은 구조(논문에서는 총 6개)
- 하나의 인코더 층은 크게 총<span style="background:rgba(240, 107, 5, 0.2)"> 2개의 서브층(sublayer)</span>인 <span style="background:rgba(240, 107, 5, 0.2)">셀프 어텐션</span>과 <span style="background:rgba(240, 107, 5, 0.2)">피드 포워드 신경망</span>으로 구성
- 멀티 헤드 셀프 어텐션은 셀프 어텐션을 병렬적으로 사용하였다는 의미고, 포지션 와이즈 피드 포워드 신경망은 우리가 알고있는 일반적인 피드 포워드 신경망을 의미

![[Pasted image 20250313161437.png]]

## Self-Attention
 먼저 어텐의 작동절차와 의미를 보자. 어텐션 함수는 주어진 '쿼리(Query)'에 대해서 모든 '키(Key)'와의 유사도를 각각 구한다. 그리고 구해낸 이 유사도를 가중치로 하여 키와 맵핑되어있는 각각의 '값(Value)'에 반영한다.  그리고 유사도가 반영된 '값(Value)'을 모두 가중합하여 리턴한다. 즉, 어텐션은 특정 쿼리에 대해 연관도에 따라서 단어들을 선별적으로 추려 볼 수 있도록 하자는 것이다.

![[Pasted image 20250313161756.png]]


셀프어텐션에서 Q,K,V는 모두 입력 문장의 모든 단어 벡터들을 뜻한다. 즉, 입력문장 내의 단어들끼지 자기 유사도를 구하는 셈이다. 이 효과는 문장 내에 대명사 등의 단어 연관을 추정 가능토록 한다. 예시로 아래 문장에서는 그것(it)이 동물(animal)과 연관되었을 확률이 높다는 것을 찾아낸다.

![[Pasted image 20250313161648.png]]


###  Q, K, V 벡터
각 단어(1 x $d_{model}$)로부터 Q, K, V 벡터를 얻어내야 하는데 이때 Q벡터, K벡터, V벡터의 차원은 (1 x $d_{model}$ / num_heads) 의 값으로 결정된다. (num_heads는 논문에서는 8)
따라서 가중치 크기는 $d_{model}\times(d_{model}\text{/num\_heads})$ 이다.


![[Pasted image 20250315125645.png]]
student 단어에서 3가지 벡터는 얻어내는 모습
단어 (1 x $d_{model}$) x 가중치 $W^Q, W^K, W^V$ ($d_{model}\times(d_{model}\text{/num\_heads})$ ) -> Q,K,V ($1\times(d_{model}\text{/num\_heads})$)

### Scaled dot-product Attention

Q, K, V 벡터를 얻었다면 지금부터는 기존에 배운 어텐션 메커니즘과 동일하다. 각 Q벡터는 모든 K벡터에 대해서 어텐션 스코어를 구하고, 어텐션 분포를 구한 뒤에 이를 사용하여 모든 V벡터를 가중합하여 어텐션 값 또는 컨텍스트 벡터를 구한다. 그리고 이를 모든 Q벡터에 대해서 반복한다.

어텐션 함수의 종류는 다양한데, 여기서는  Scaled dot-product Attention을 사용한다. $score(q, k)=q⋅k/\sqrt{n}$




![[Pasted image 20250315131820.png]]위의 그림에서 어텐션 스코어는 각각 단어 I가 단어 I, am, a, student와 얼마나 연관되어 있는지를 보여주는 수치이다. 트랜스포머에서는 두 벡터의 내적값을 스케일링하는 값으로 K벡터의 차원을 나타내는 dk에 루트를 씌운 dk 사용하는 것을 택했다. 앞서 언급하였듯이 논문에서 dk는 dmodel/num_heads라는 식에 따라서 64의 값을 가지므로 dk는 8의 값을 가진다.

이제 어텐션 스코어에 소프트맥스 함수를 사용하여 어텐션 분포(Attention Distribution)을 구하고, 각 V벡터와 가중합하여 어텐션 값(Attention Value)을 구한다. 이를 단어 I에 대한 어텐션 값 또는 단어 I에 대한 컨텍스트 벡터(context vector)라고 한다. am에 대한 Q벡터, a에 대한 Q벡터, student에 대한 Q벡터에 대해서도 모두 동일한 과정을 반복하여 각각에 대한 어텐션 값을 구한다.


### 행렬 표현
이 반복작업을 행렬 연산으로 표현해보자.
$Attention(Q, K, V) = softmax({QK^T\over{\sqrt{d_k}}})V$


![[Pasted image 20250315132248.png]]
모든 문장을 행렬로 구성하여 Q, K, V 행렬을 추출한다
입력행렬 (N x $d_{model}$ ) x 가중치  $W^Q, W^K, W^V$ ($d_{model}\times(d_{model}\text{/num\_heads})$ ) -> Q,K,V ($N\times(d_{model}\text{/num\_heads})$)
여기서 N은 문장길이(seq_lengh)를 의미한다

![[Pasted image 20250315132312.png]]
Q행렬과 전치K행렬을 곱한 결과는 각 단어의 내적이 원소(스칼라)가 되는 행렬이 된다


![[Pasted image 20250315133553.png]]
스케일링 후 소프트맥스 변환을 하여 V행렬을 곱한 결과는 어텐션 행렬이 된다



### Multi-head Attention
앞선 어텐션 과정에서 입력차원($d_{model}$)을 $(d_{model}\text{/num\_heads})$ 차원으로 축소하였다. 이는 한번의 어텐션을 하는 것보다 여러번의 어텐션을 병렬로 사용하는 것이 더 효과적이었기 때문이다. 


![[Pasted image 20250315134330.png]]그래서 축소된 차원을 $\text{num\_heads}$ 개의 병렬 어텐션을 수행한다. 이때 각각의 어텐션 값 행렬을 어텐션 헤드라고 부르며, 가중치$W^Q,W^K,W^V$ 행렬의 값은 어텐션 헤드마다 전부 다르다.


이러한 병렬 어텐션은 동일한 자료를 다른 시각으로 정보를 수집하는 듯한 효과를 준다. 예를 들어 앞서 사용한 예문을 보자.  '그 동물은 길을 건너지 않았다. 왜냐하면 그것은 너무 피곤하였기 때문이다.' 단어 그것(it)이 쿼리였다고 해보자. it에 대한 Q벡터로부터 다른 단어와의 연관도를 구하였을 때 첫번째 어텐션 헤드는 '그것(it)'과 '동물(animal)'의 연관도를 높게 본다면, 두번째 어텐션 헤드는 '그것(it)'과 '피곤하였기 때문이다(tired)'의 연관도를 높게 볼 수 있다. 각 어텐션 헤드는 전부 다른 시각에서 보고있기 때문이다.



![[Pasted image 20250315134721.png]]
병렬 어텐션을 모두 수행하였다면 모든 어텐션 헤드를 연결(concatenate)한다. 모두 연결된 어텐션 헤드 행렬의 크기는 $(N, d_{model})$ 이다.



![[Pasted image 20250315135128.png]]
어텐션 헤드를 모두 연결한 행렬은 또 다른 가중치 행렬 $W^o$을 곱하게 되는데, 이렇게 나온 결과 행렬이 멀티-헤드 어텐션의 최종 결과물이다. 이때 결과물인 멀티-헤드 어텐션 행렬은 인코더의 입력이었던 문장 행렬의 $(N, d_{model})$ 크기와 동일하다.

다시말해, <span style="background:rgba(240, 107, 5, 0.2)">인코더의 입력으로 들어왔을 때의 행렬크기는 서브층(멀티헤드 어텐션, 피드포워드)을 지나는 동안 계속 유지되어야 한다</span>. 왜냐하면 트랜스포머는 동일한 구조의 인코더를 쌓은 구조이기 때문에 동일 크기로 계속 유지되어야 다음 인코더에서 다시 입력될 수 있기 때문이다.

### Padding Mask
입력 문장에 < PAD > 토큰이 있을 경우 어텐션에서 사실상 제외하기 위한 연산입니다.



![[Pasted image 20250315135738.png]]
단어 < PAD > 는 실질적인 의미를 가진 단어가 아니다. 그래서 트랜스포머에서는 Key의 경우에 < PAD > 토큰이 존재한다면 이에 대해서는 유사도를 구하지 않도록 마스킹(Masking)을 해준다. 여기서 마스킹이란 어텐션에서 제외하기 위해 값을 가린다는 의미이다. 

어텐션 스코어 행렬에서 행에 해당하는 문장은 Query이고, 열에 해당하는 문장은 Key이다. 그리고 Key에 < PAD >가 있는 경우에는 해당 열 전체를 마스킹을 한다.


![[Pasted image 20250315140100.png]]
마스킹을 하는 방법은 어텐션 스코어 행렬의 마스킹 위치에 매우 작은 음수값을 넣어주는 것이다. 그러면 소프트맥스 함수를 지난 후 해당 위치의 값은 0이 되어 단어 간 유사도를 구하는 일에 반영되지 않게 된다.


## Position-wise FFNN


$FFNN(x) = MAX(0, x{W_{1}} + b_{1}){W_2} + b_2$

![[Pasted image 20250315140230.png]]
여기서 x는 앞서 멀티 헤드 어텐션의 결과로 나온 $(N, d_{model})$의 크기를 가지는 행렬이다. 가중치 행렬 W1은 $(d_{model}, d_{ff})$의 크기를 가지고, 가중치 행렬 W2은 $(d_{ff}, d_{model})$의 크기를 가진다. 논문에서 은닉층의 크기인 $d_{ff}$는 2,048의 크기를 가진다.


여기서 매개변수 W1, b1, W2, b2는 하나의 인코더 층 내에서는 다른 문장, 다른 단어들마다 정확하게 동일하게 사용되나, 인코더 층마다는 다른 값을 가진다.

![[Pasted image 20250315140634.png]]
두번째 서브층을 지난 인코더의 최종 출력은 여전히 인코더의 입력의 크기였던 $(N, d_{model})$의 크기가 보존되고 있다. 하나의 인코더 층을 지난 이 행렬은 다음 인코더 층으로 전달되고, 다음 층에서도 동일한 인코더 연산이 반복된다.


## Add & Norm


트랜스포머에서는 이러한 두 개의 서브층을 가진 인코더에 추가적으로 사용하는 기법이 있는데, 바로 Add & Norm이다. 더 정확히는 잔차 연결(residual connection)과 층 정규화(layer normalization)를 의미한다.


### Residual connection


![[Pasted image 20250315140948.png]]
위 그림은 입력 x와 x에 대한 어떤 함수 F(x)의 값을 더한 함수 H(x)의 구조를 보여줍니다. 어떤 함수 F(x)가 트랜스포머에서는 서브층에 해당된다.

잔차 정보를 가져가기 위해, 서브층의 입력과 출력을 더하는 연산을 수행한다. 


![[Pasted image 20250315141306.png]]
이를 식으로 표현하면 $x+Sublayer(x)$ 이며,
서브층이 멀티 헤드 어텐션이었다면 다음처럼 표현한다.
$H(x) = x+Multi-head\ Attention(x)$


### Layer Normalization



잔차 연결을 거친 결과는 이어서 층 정규화 과정을 거친다. 잔차 연결의 입력을 x, 잔차 연결과 층 정규화 두 가지 연산을 모두 수행한 후의 결과 행렬을 LN이라고 하였을 때, 잔차 연결 후 층 정규화 연산을 수식으로 표현하자면 다음과 같다.

$LN = LayerNorm(x+Sublayer(x))$

![[Pasted image 20250315141605.png]]
층 정규화는 **텐서의 마지막 차원**$d_{model}$에 대해서 평균과 분산을 구하고, 이를 가지고 어떤 수식을 통해 값을 정규화하여 학습을 돕는다. 층 정규화를 수행한 후에는 벡터 $x_i$는 $ln_i$라는 벡터로 정규화가 된다.
$ln_{i} = LayerNorm(x_{i})$



층 정규화의 목표는 데이터의 분포를 일정하게 만들어서 모델 학습을 더 안정적이고 효율적으로 만드는 것이다. 여기서는 층 정규화를 두 가지 과정으로 나누어서 볼 수 있다.  먼저 평균과 분산으로 데이터의 분포를 정규화한다. 그리고 감마와 베타를 도입하여 모델의 유연성울 높인다. 여기서 감마는 스케일, 베타는 이동을 의미한다. 

- 정규화
	- 	$\hat{x}_{i, k} = \frac{x_{i, k}-μ_{i}}{\sqrt{σ^{2}_{i}+\epsilon}}$
	 -  $x_i$는 벡터인 반면, 평균 $μ_i$과 분산 $σ_i^2$은 스칼라이다. 벡터 $x_i$의 각 차원을 $k$라고 하였을 때, $x_{i,k}$는 다음의 수식과 같이 정규화 할 수 있다. $ϵ$은 분모가 0이 되는 것을 방지하는 값이다.

- 정규화 후 스케일링 및 이동 학습
	- $\gamma$ 와 $\beta$ 를 도입한 최종수식은 다음과 같다.
	- $\gamma$ 와 $\beta$ 는 학습가능한 파라미터이며, 각각 1과 0으로 초기화한다.
	-  $ln_{i} = γ\hat{x}_{i}+β = LayerNorm(x_{i})$

## Look-ahead mask

디코더의 첫번째 서브층 Masked Multi-head Self-Attention 에 대해서 보자.

디코더도 인코더와 동일하게 임베딩 층과 포지셔널 인코딩을 거친 후의 문장 행렬이 입력된다. 트랜스포머 또한 seq2seq와 마찬가지로 교사 강요(Teacher Forcing)을 사용하여 훈련되므로 학습 과정에서 디코더는 번역할 문장에 해당되는 `<sos> je suis étudiant`의 문장 행렬을 한 번에 입력받고 이 문장 행렬로부터 각 시점의 단어를 예측하도록 훈련된다.

여기서 문제가 있다. seq2seq의 디코더에 사용되는 RNN 계열의 신경망은 입력 단어를 매 시점마다 순차적으로 입력받으므로 다음 단어 예측에 현재 시점을 포함한 이전 시점에 입력된 단어들만 참고할 수 있다. 반면, 트랜스포머는 문장 행렬로 입력을 한 번에 받으므로 현재 시점의 단어를 예측하고자 할 때, 입력 문장 행렬로부터 미래 시점의 단어까지도 참고할 수 있는 현상이 발생한다.

이를 위해 트랜스포머의 디코더에서는 현재 시점의 예측에서 현재 시점보다 미래에 있는 단어들을 참고하지 못하도록 룩-어헤드 마스크(look-ahead mask)를 도입한다. 직역하면 '미리보기에 대한 마스크'이다.

![[Pasted image 20250315143404.png]]
룩-어헤드 마스크(look-ahead mask)는 디코더의 첫번째 서브층에서 이루어진다. 디코더의 첫번째 서브층인 Masked Multi-head Self-Attension 층은 인코더의 첫번째 서브층인 Muti-head Self-Attension 층과 동일한 연산을 수행하나, 오직 다른 점은 어텐션 스코어 행렬에서 마스킹을 적용한다는 점만 다르다.

쿼리 행과 키 열을 내적하여 스칼라값을 얻는다. 여기서 자기 자신보다 미래에 있는 단어들은 참고하지 못하도록 마스킹을 한다. 이때 더불어 패딩 마스크도 포함하도록 구현한다.




## Encoder-Decoder Attention

디코더의 두번째 서브층은 멀티 헤드 어텐션을 수행한다는 점에서는 이전의 어텐션들(인코더와 디코더의 첫번째 서브층)과는 공통점이 있으나 이번에는 셀프 어텐션이 아니다. 

인코더-디코더 어텐션은 Query가 디코더인 행렬인 반면, Key와 Value는 인코더 행렬이기 때문입니다. 다시 한 번 각 서브층에서의 Q, K, V의 관계를 정리해보자.

```
인코더의 첫번째 서브층 : Query = Key = Value
디코더의 첫번째 서브층 : Query = Key = Value
디코더의 두번째 서브층 : Query : 디코더 행렬 / Key = Value : 인코더 행렬
```


![[Pasted image 20250315144324.png]]
 Key와 Value는 인코더의 마지막 층에서 온 행렬로부터 얻으며, Query는 디코더의 첫번째 서브층의 결과 행렬로부터 얻는다.
